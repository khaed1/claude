# Logos

- `pondpad-mark.svg`: the lily pad mark, ink `#6fd08c` (`lily`, night). Use on `pond-deep`, `pond` and photos behind a `pond-deep` plate.
- `pondpad-mark-day.svg`: the same mark, ink `#17784a` (`lily`, day). Use on day grounds.
- `pondpad-app-icon.svg`: the mark on `pond-deep` (#0a1719) with a firefly (`#ffd166`). Favicon, social avatar, PWA icon.
- `pip-frog.svg`: Pip, the mascot, inks `lily` night, `ink` night, `pond-deep`, `ripple`. Moments only: the Leap modal, empty states, 404, airdrop page.

The wordmark is live type ("pondpad", `Lilita One`), not a file.
