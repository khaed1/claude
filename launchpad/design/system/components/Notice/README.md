# Notice

A message inside the page, never a blocking modal. `pp-notice-tax` (gold): the early-bird (snipe) tax countdown on a coin or the $PONDPAD sale, live seconds. `pp-notice-chorus` (lotus): swarm events, the takeover banner with a link to the swarm's reasoning. `pp-notice-danger` (coral): wrong network, failed transaction with the fix. Plain `pp-notice`: risk lines and info. Lead with a bold sentence that says what is happening, then one sentence on what it means. Copy: `SITE-COPY.md`.
