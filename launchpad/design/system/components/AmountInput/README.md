# AmountInput

The amount field in the trade box, stake form and sale. Big number, the token picker on the right (IMD, ETH, USDG, or the coin when selling), presets underneath (IMD: 5 / 10 / 25 / 50; ETH: 0.01 / 0.05 / 0.1; selling: 25% / 50% / 100%) and Max. Show the wallet balance under the label. Validate as the user types: "Not enough IMD for that. Try a smaller amount or pay with ETH."
