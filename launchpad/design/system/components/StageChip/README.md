# StageChip

Shows where a coin is in its life: Egg, Tadpole or Frog. Egg = launched in the last 60 seconds (max-buy window); Tadpole = on the bonding curve (optionally with the % to the Leap); Frog = graduated (optionally "leapt 3d ago"). Always on coin cards and next to the coin name on the coin page. Classes: `pp-stage pp-stage-egg|tadpole|frog`. The word carries the meaning; color only helps.
