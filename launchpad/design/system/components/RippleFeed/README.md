# RippleFeed

The live feed of what is happening in the pond: buys (lily "bought"), sells (coral "sold"), spawns and Leaps (gold). One line under the top bar on every page, scrolling slowly to the left (paused on hover, static with reduced motion, hidden on phones except on Explore). Each chip: short address, verb, amount with its payment token ("12.5 IMD", "0.02 ETH"), ticker; it links to the coin. New chips get the ripple ring once. Data: the indexer's trade stream.
