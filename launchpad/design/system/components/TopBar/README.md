# TopBar

Desktop and tablet header: logo (mark + live wordmark) → Explore, $PONDPAD, The Pond, Docs → search (coins, tickers, creator addresses; ⌘K) → Spawn (lily, small) → wallet (address, or "Connect wallet"). The wallet menu holds Profile, Transparency, theme toggle, Disconnect. On phones it shrinks to logo, search icon and wallet; the tab bar takes the navigation.
