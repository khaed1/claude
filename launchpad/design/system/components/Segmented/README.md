# Segmented

Choosing one of a few options in place. `pp-seg is-trade` for Buy / Sell at the top of the trade box (buy tints lily, sell tints coral). `pp-seg` for pay-with (IMD / ETH / USDG) and small filters. `pp-tabs` for switching panels on a page: on the coin page Trades / Holders / Creator / Chorus; on Profile Holdings / Created / Rewards / Activity. Buttons use `aria-pressed`; tabs use `role=tab` + `aria-selected`.
