# PondPad design

The look, voice and page layouts for the PondPad site, settled before the frontend is built (D-66).

| File | What it is |
|---|---|
| [`UX-RESEARCH.md`](UX-RESEARCH.md) | Pump.fun and Pons: what works, what doesn't, what PondPad takes and adds |
| [`moodboard.html`](moodboard.html) | Mood board: the intended aesthetic (night pond, textures, palette with its story, type, moments). Published: https://claude.ai/artifact/NRkqRuNW7edMkJnt8zGsVL |
| [`system/README.md`](system/README.md) | **Brand book**: idea, traits, vocabulary, voice, logo, mascot, color, type, shape, motion, icons, layout, do and don't |

Design system (browsable, published): https://claude.ai/artifact/B4narVLex3zGLPzLa5zbmi

Regenerate after changing tokens or previews:

```bash
cd launchpad/design
python3 build_tokens.py      # tokens.json + tokens.css, fails on any contrast pair below 4.5:1 (3:1 for marks)
python3 build_previews.py    # component previews + preview-all.html
```

The repo is the source: edit here, then republish the design system artifact from `system/` (+ `fonts/`).

Reviewed against the impeccable design checklist (impeccable.style; the user's suggestion): no emoji or glyph icons, browser surfaces themed, at most two badges per card, no eyebrow labels, motion only where something happened, contrast verified in both themes.
