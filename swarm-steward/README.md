# Swarm Steward (working name)

An AI DAO that runs projects after launch: IMD swarm panels judge, contracts with hard limits execute, and holders keep a veto. PondPad (`../launchpad/`) is meant to be its first client.

Separate project from PondPad. It lives here because the session could not create a new repository; move it to its own repo when one exists.
