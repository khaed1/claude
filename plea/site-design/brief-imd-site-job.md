Build the PLEA website: a static Vite + React + TypeScript + viem export for IPFS, label plea (plea.sites.imd.fun). It reads the PLEA contracts on Ethereum (addresses from the launch's deployment), the IMD Indexer job's API for history, and api.imd.fun for oracle requests. Deploy and change no contracts. The contracts' README (github.com/khaed1/plea) and ABIs are the source of truth; read every value (fees, windows, caps, seasons) from chain.

DESIGN SYSTEM (exact): github.com/khaed1/claude at commit {PIN}, folder plea/site-design/. Use tokens.css and components.css as they are. components.html is the markup of every component in every state; pages/*.html are the mockups of every page (layout, copy, components); the dashed "Design reference · other states" band at the bottom of each mockup lists that page's other states: build them all, but it is not site content. PAGE-KIT.md holds the rules. sample-data.json is mockup data only. No other colours, fonts or effects. Never IMD's diamond logo; the footer says the site is not an official IMD page.

PAGES (as in the mockups): Home and how it works (hero, live stats, latest six verdicts, the fact score table, fees, contracts, the owner's one power); Buy (quote, slippage, fee split, buy record, cashback; the 90-minute launch fee and 5M cap; after the Cabal dies, a plain Sell); Plead (amount chips, live fact score and need, the plea text, the "Sell automatically if approved" box on by default); a plea's status page at #/p/<id> (stamp, countdowns, sell, record points, appeal, objections, timeline, share); Letters (the Etherscan how-to, commands, a letter checker, costs, status(address)); Objections (open windows, the object form, rulings); Seasons (leaderboard of 25 with the seat multiplier, the 60-point line, past seasons, close season); the Wall (filters, compact cards); Claim (any address, delegate.xyz); Profile (balances, buy record, display name, pleas, seasons); the X share card per plea.

MUST HAVE:
- A colour per verdict state with the state in words on the stamp: APPROVED, DENIED, PENDING (striped, with its countdown), NO VERDICT, LAPSED (dashed), SOLD, OVERTURNED, UPHELD, OBJECTION, SUSTAINED, OVERRULED. The stamp lands once when a verdict arrives live; nothing else animates; honour reduced motion.
- Every text box (plea, appeal, objection, letter, name) uses text-check.js: a live UTF-8 byte counter "193 / 280 bytes" and the contract's checks, with submit disabled until they pass. Plea text is always rendered as text, never HTML.
- Auto-sell box: checked sends Letterbox.plead(amount, text) / appealAuto(originalId, text) (escrow, fees paid in PLEA: 0.50 IMD oracle fee + 0.25 IMD tip; 0.35 IMD of a delivered sale to the season pot); unchecked is the manual flow (approve 0.50 IMD, submitSell, then executeSell(minOut) inside 7 minutes). Show both cost breakdowns.
- Before paying, show the fact score and need = 71 - fact; above 45, disable submit and say the plea cannot pass (CannotPass). Show cooldowns.
- Seasons: points with Seasons.pointsFor / holdsSeat (x1.2 rounded down for IMD seat holders), shares from Seasons.shareBps, the 10,000,000 PLEA bonus in the first six seasons, a record-points button while points are held, close season after the 1-hour grace.
- Claim: PleaDistributor.claim(index, account, amount, proof) for any typed address from a published claims.json, with isClaimed; delegate.xyz v2 (0x00000000000000447e69651d841bD8D104Bed493): list getIncomingDelegations(connected) and claim for each vault; the PLEA lands on the vault.
- Profile: Letterbox.setName / nameOf, "This is your current name" for the wallet's own name.
- Share card: a 1200 x 675 PNG drawn in the browser from the share-card component; "Share on X" (twitter.com/intent/tweet with text and the #/p/<id> link), "Download image", "Copy image".
- After the Cabal dies (33 hours without a verdict): the banner on every page, Plead and Objections closed, Sell on Buy.
- sIMD has 24 decimals. Cashback earned = the sum of the Stacker's credits for the hook and the wallet (events). Every buy passes abi.encode(buyer) as hookData. Every write sends an explicit gas limit (estimate x 1.3). Decode the contracts' custom errors into the plain words the mockups use.

WALLET: one Connect button top right on every page; everything reads without a wallet; actions say "Connect in the top bar to ...". Switch to Ethereum when needed. Per-button states: wallet, busy, done with an explorer link, error with the fix (toasts as in components.html).

BUILD: self-host Archivo (variable, wdth 62-125) and IBM Plex Mono 400/500/600 as woff2 (SIL OFL), Phosphor Bold icons (MIT). Light theme by default, dark via the toggle, stored in localStorage "plea-theme" and set before first paint. Hash routing, relative base. Public Ethereum RPCs with fallback.

QA before hosting: WCAG 2.1 AA (body text 4.5:1, large 3:1, keyboard focus always visible, targets 44 px, colour never the only signal); every page and every state at 360, 768 and 1280 px, light and dark, in a real browser against the live contracts: no horizontal scroll, no console errors, no axe violations (tools/check.mjs in the design folder does this for a page); compare each with its mockup and fix the differences, then one more round. Refuse: gradients other than the pending stripes, blur, glass, glows, soft shadows, new colours, emoji as icons, modals where a page works, placeholder text.
