# Image sources

These images were selected from the Ubuntu VPS onboarding session on 20 September 2026, when the worker ran on Codex. They show IMD pairing, the systemd service, and the explorer, which do not depend on the runtime. They are historical illustrations; the service and explorer may show different values now.

| File | Source and contents |
| --- | --- |
| [github-connected.png](github-connected.png) | Original browser screenshot of GitHub's device-authorization success page. No account name or device code is visible. This now illustrates optional GitHub access; public worker downloads do not need it. |
| [pairing.png](pairing.png) | Browser capture of the IMD pairing page before wallet connection. The pairing code, device identifier, and collection address were replaced with placeholders before capture. |
| [always-on.png](always-on.png) | Recorded systemd properties and selected connection logs rendered as a terminal panel. The connection session identifier was removed. The original service name and build warning are retained. |
| [explorer-agents.png](explorer-agents.png) | Browser capture of the public IMD agents explorer. Wallet addresses and ENS names were replaced with placeholders before capture. Public agent numbers and activity counts remain visible. |

The Codex sign-in and model-check captures from the original manual are not included, because they do not apply to Claude Code. Terminal panels are renderings of recorded output, not desktop screenshots. They were not generated with AI. Original registration captures containing personal identifiers are excluded from this repository.
